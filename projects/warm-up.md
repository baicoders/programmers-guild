# 🟢 Warm-up Quest: Your First Repo

**Time:** 1 hour · **Repo name:** `hello-guild`

[← Back to the board](../README.md)

## The mission

Before you write any real code, learn the workflow you'll repeat for **every** project: create a repo, make changes,
commit them, and push them to GitHub.

Your "project" is a repository about **you**.

## Requirements

- [ ] Create a new **public** repository on your own GitHub account named `hello-guild`.
- [ ] Get that repository onto your computer.
- [ ] Add a `README.md` with:
  - your name or handle
  - which language(s) you want to learn and why
  - one project from the board you plan to build first
- [ ] Make **at least 3 separate commits**, each with a clear message.
- [ ] Push all your commits to GitHub.
- [ ] Edit a file **on the GitHub website**, then bring that change down to your computer.

## Things to research

`git clone` · `git status` · `git add` · `git commit` · `git push` · `git pull` · `git log` · Markdown syntax

## Questions you should be able to answer afterwards

1. What's the difference between your **local** repository and the **remote** one on GitHub?
2. What does the **staging area** do? Why does `git add` exist at all?
3. What happened when you edited on GitHub and then tried to push without pulling first? (Try it!)
4. What is `origin`?

<details>
<summary>💡 Hint 1: Where do I even start?</summary>

There are two ways to begin: create the repo on GitHub and **clone** it, or create a folder locally with **init** and connect it
to GitHub afterwards. Cloning is easier the first time.
</details>

<details>
<summary>💡 Hint 2: GitHub keeps asking for a password</summary>

GitHub stopped accepting account passwords for Git over HTTPS. Look up **"GitHub personal access token"** or
**"GitHub CLI auth login"** or **"SSH keys GitHub"**. Pick one method and learn it properly: you'll use it for every project.
</details>

<details>
<summary>💡 Hint 3: I see my changes but nothing is on GitHub</summary>

Run `git status` and read every line. Committing saves changes **locally**. Something else sends them to GitHub.
</details>

## Stretch goals

- Turn your `hello-guild` README into a GitHub **profile README** (look up "GitHub special repository profile").
- Make a new **branch**, commit to it, and merge it back into `main`.
