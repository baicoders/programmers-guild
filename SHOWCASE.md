# 🏆 Guild Showcase

Projects built by guild members. Finished one? Add yourself!

## How to add your project

This is your last lesson for the project: contributing to someone else's repository.

1. **Fork** [baicoders/programmers-guild](https://github.com/baicoders/programmers-guild) (or create a **branch**, if you have write access).
2. Add **one row** to the bottom of the table below.
3. **Commit** with a clear message, e.g. `Add python-expense-tracker to showcase`.
4. Open a **Pull Request**. Describe what you built and one thing you learned.
5. Respond to any review comments. That's normal on real teams too!

**Requirements for being added:** your project meets the [Definition of Done](README.md#-definition-of-done).
